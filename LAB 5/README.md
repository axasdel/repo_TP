## *Реализация паттернов*

### ADAPTER

**Смысл:** преобразование интерфейса одного класса в интерфейс другого, ожидаемый клиентом. Таким образом классы с несовместимыми интерфейсами работать вместе.

**Файлы:** `adapter/*.java`

**Классы:**
- `TemperatureSensor`: целевой интерфейс, ожидаемый клиентом (метод `getCelsius()`)
- `OldFahrenheitSensor`: адаптируемый класс со старым интерфейсом (метод `getFahrenheit()`)
- `SensorAdapter`: адаптер, реализует `TemperatureSensor` и преобразует значение из Фаренгейта в Цельсий
- `Main`: клиент

**Вывод:**
Датчик (F): 98.6
Датчик (C): 37.0


### BRIDGE

**Смысл:** разделение абстракции и её реализации на две независимые иерархии, чтобы их можно было изменять независимо друг от друга.

**Файлы:** `bridge/*.java`

**Классы:**
- `Exporter`: интерфейс реализации (метод `export(String data)`)
- `PdfExporter`, `CsvExporter`: конкретные реализации экспорта
- `Report`: абстракция, хранящая ссылку на `Exporter`
- `SalesReport`: расширенная абстракция (конкретный отчёт)
- `Main`: клиент

**Вывод:**
PDF: Продажи за месяц: 1000
CSV: Продажи за месяц: 1000


### PROXY

**Смысл:** предоставление суррогатного объекта вместо реального для контроля доступа к нему. Прокси и реальный объект реализуют общий интерфейс, поэтому клиент не знает, с кем работает.

**Файлы:** `proxy/*.java`

**Классы:**
- `Document`: интерфейс субъекта (метод `read()`)
- `RealDocument`: реальный субъект с содержимым документа
- `ProtectedDocumentProxy`: прокси с проверкой уровня доступа (роль пользователя)
- `Main`: клиент

**Вывод:**
[editor] Полный текст документа
[guest] [только заголовок] Заголовок документа
[unknown] Доступ запрещён
